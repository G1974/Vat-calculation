NAME OF APP: VAT CALCULATION

Net ➜ With VAT //// With VAT ➜ Net

Predefined VAT rates:

24%, 13%, 6%, or "Other" (to enter your own percentage)

Input validation (e.g. negative amounts, incorrect percentages)

Clear all fields with a single button

Display of final amount and VAT amount with 2-decimal precision

Language: Visual Basic .NET ////// Environment: Visual Studio Community 2022 or later  ///\\\  Platform: Windows Forms (.NET Framework)

How to Run

Open the project in Visual Studio.

Build the project (Ctrl + Shift + B).

Press Start  to run the application.

Use the interface to calculate VAT.
